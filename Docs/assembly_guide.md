## Steps

1. Inspect the PCB and printed parts.
2. Solder low-profile components first.
3. Solder connectors, buttons, and other tall components.
4. Flash firmware before final enclosure assembly.
5. Mount the PCB into the bottom case.
6. Attach controls, top case, and fasteners.
7. Run the testing plan.
