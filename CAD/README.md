# CAD

Use this folder for the full mechanical design.

Expected review files:

- `assembly.step`: full final assembly export
- `assembly.stl`: optional preview/export
- `source/`: editable CAD source files or Onshape link
- `parts/`: STEP exports for major parts
- `print_files/`: STL files ready for slicing
- `renders/`: screenshots and presentation renders

The included STEP and STL files are placeholders. Replace them with real CAD exports before submitting the project for review.
