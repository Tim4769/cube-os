# PCB

Use this folder for electrical design, manufacturing outputs, and PCB screenshots.

Expected review files:

- `schematic.pdf`: exported schematic
- `pcb_render_front.png`: board render or screenshot
- `pcb_render_back.png`: board render or screenshot
- `source/`: KiCad project source
- `gerbers/`: zipped fabrication files
- `production/`: PCBA BOM, CPL, and fabrication notes
- `3d_models/`: front/back PCB 3D images

The included KiCad files are placeholders. Open the project in KiCad, build the real schematic and PCB, then export manufacturing outputs before review.
