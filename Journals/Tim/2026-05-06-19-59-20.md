While resolving the DRC errors, I found that some footprints (for example, the camera connector) had solder mask expansion set to 0.1 mm, which caused the pads to short to each other. I set the solder mask expansion to 0.05 mm to prevent pin shorting during production and to resolve the DRC errors.

When resolving the DRC errors, some errors indicate that the ground plane on the first layer is not connected. This is due to traces separating them, but when I clicked on the error, it only showed the whole top ground plane, not the specific pin connected to the plane, which is a little inconvenient when manually finding which pin with a GND island is not connected to the main top-layer ground plane.
