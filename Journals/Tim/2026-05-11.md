VSS pins are changed to GND

The ESP32 model has changed. N8R8 to N8R2 so that these pins can be kept:

CAM_D0 = GPIO35
CAM_D1 = GPIO36
CAM_D2 = GPIO37

R6 is changed from 2.4k ohms to 3.6k ohms

each display’s LEDA is connected to a 10 ohms resistor in series to limit current

AVDD, DOVDD, and DVDD have a 0.1 uF cap

The linear regulator is changed from output of 2.5V to 2.8V with LDLN025J28R for AVDD

Discussed with the mechanical team, where all the connectors that have connections towards the outside have to be concentrated on one side of the PCB because the cube itself will be bigger than the PCB side, if placed on a different side, some connectors like USB-C or buttons cannot be reached.

Planning to use the GPIO extension chip to gain more GPIOs from my ESP32 chip, model is Texas Instruments TCA6408A
