# Modifying leg to be suitable for servo motor

- This allows the creation of a motor attachment unit with the size of 4.5 mm diameter to be slide in and attached to the front pivot as shown → this will be done using an M3 screws with ISO threads so the motor attachment and front pivot will be rigid but allowing rotation in the joint
